# AgriBusiness.pk — Full-Site Revamp: Design Refinement + Backend Improvements + Dummy Data + New Features

**Direction chosen:** Refine the existing Evergreen/Harvest-Gold "mandi ledger" identity — strip the AI-slop decoration layer, enforce token + typography discipline, fix every functional bug found in the audit, seed rich demo data, and add new features. No dark mode (the dark Exchange-Board hero keeps contrast moments).

---

## Phase 0 — Design System Cleanup (`src/styles.css`, `src/routes/__root.tsx`, new `DESIGN.md`)

1. **Consolidate tokens**: promote the hardcoded hero greens (`#08160F`, `#0D2A1D`) and gold-brown (`#3D2A05`) into `@theme` tokens; align the duplicate shadcn `:root` vars with `@theme` values; fix `on-secondary` contrast (dark text on gold, not white); delete the dormant `.dark` block.
2. **Delete the slop layer**: ~16 dead utilities (`glass`, `glow-green`, `glow-gold`, `premium-shadow`, `btn-shine`, `text-shimmer`, `gradient-mesh`, `animate-float/spin/bounce-slow`…) and collapse the two shadow/eyebrow/grid/heading systems into one each.
3. **Typography discipline**: global minimum font size (replace every `text-[9px]/[10px]/[11px]` across the app with ≥12px equivalents); load fonts once (remove the duplicate `@import` from CSS); fix the malformed Material Symbols `FILL@100..700` axis URL.
4. **A11y base**: consistent visible `:focus-visible` ring; `prefers-reduced-motion` also disables `scroll-behavior: smooth` and the ticker marquee; RTL Nastaliq line-height 2→2.75.
5. **Shared motion variants**: export the `ease` arrays from `Reveal.tsx` so Hero/FeaturedProjects stop re-declaring them; document in `DESIGN.md` (refero format: colors, typography, spacing, components, motion).
